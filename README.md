# Git & GitHub Command Cheat Sheet

A comprehensive reference guide for essential Git commands organized by the Git lifecycle and common workflows.

---

## 1. Working Directory & Navigation

Commands to navigate directories, clone repositories, and check file status.

```bash
# Change directory to a specific folder
cd "folder_name"

# Move up one directory level
cd ..

# Clone an existing repository from GitHub
git clone [https://github.com/username/repository.git](https://github.com/username/repository.git)

# Open the current directory in File Explorer (Windows)
explorer .

# Check the status of the working directory and staging area
git status

# Initialize a new Git repository in the current folder
git init
